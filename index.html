한국항공대학교 석사 졸업예정

19.03-24.08

한국항공대 학사 졸업

저는 대규모 분산 병렬 시스템을 연구하는 연구자로, 특히 병렬성을 극대화하면서도 제한된 자원을 얼마나 효율적으로 활용할 수 있는지에 관심을 가지고 있습니다. 단순히 더 많은 하드웨어를 추가하는 Scale-Up 방식의 성능 향상보다는, 기존 자원의 활용도를 극대화하여 시스템 전체의 효율과 확장성을 높이는 시스템 설계를 연구하고 있습니다.

현재는 파이프라인 병렬화, 자원 스케줄링, 런타임 시스템을 중심으로, 이기종 가속기 환경에서 딥러닝 모델을 효율적으로 실행하기 위한 시스템을 개발하고 있습니다. 이를 통해 대규모 분산 환경에서도 높은 병렬성과 자원 효율을 동시에 달성할 수 있는 시스템을 만드는 것을 목표로 하고 있습니다.

  1. SoftwareX
    PyCAN: Open-source Python software of N-dimensional Content-Addressable Network
    Yuchan Lee, Sookwang Lee, and Jaehwan Lee
    SoftwareX, 2024
    Abs DOI Code

    We propose PyCAN, the first open-source Python implementation of N-dimensional Content-Addressable Network (CAN) with full feature sets to maintain peer-to-peer structure. Existing CAN implementations supports limited functions of Distributed Hash Table (DHT), so they cannot be used in practice. However, PyCAN offers full set of features such as N-dimension coordinates, node removal followed by node taking over, and a verification method to keep peer-to-peer structure. By extensive experiments, we confirm that PyCAN supports scalable overlay structures, so it is practically usable in peer-to-peer systems.

  2. BigData
    DEPUTY: A DPU-Based Network Offloading Architecture with Minimal CPU Involvement for Stable Network Performance
    Yuchan Lee, Sooho Jang, Sookwang Lee, and 2 more authors
    In 2025 IEEE International Conference on Big Data (BigData), 2025
    Abs DOI Video

    The growing demand for High-Performance Computing (HPC) and large-scale AI services has led to a significant increase in workloads that require processing Big Data in real time. While the GPU handles most of the computation, frequent CPU intervention in network processing and data transfer often leads to system performance bottlenecks and inefficient resource utilization. To address this problem, we propose DEPUTY, a system that enables network processing without CPU involvement by offloading all network-related tasks to the Data Processing Unit (DPU). DEPUTY performs all network-related operations on the DPU, including receiving client requests, transferring data to GPU memory, checking GPU inference results, and sending the results back to the client. To achieve this, we utilize DOCA DMA and develop a ring buffer-based data structure in GPU memory, enabling efficient and synchronized data transmission between the DPU and GPU. DEPUTY employs index-based polling to minimize synchronization overhead while ensuring reliable communication. Unlike RDMA, DEPUTY does not require specialized hardware and tightly coupled network configurations on the client side, allowing compatibility with broader deployment environments. Additionally, to minimize CPU overhead during inference, the entire inference workflow is expressed as a CUDA Graph, allowing GPU to autonomously execute kernels in sequence without requiring repeated CPU intervention. Experimental results show that DEPUTY achieves up to 1.96× higher throughput compared to an existing DPUbased offloading method. Using DEPUTY, it effectively reduces CPU resource consumption and mitigates system performance bottlenecks.
